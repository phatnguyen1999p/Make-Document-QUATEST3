# E29 — HEPA: code chỉ có mức ≤ 0,01 %; BSC.01/BSC.02 có mức ≤ 0,005 % khi scan qua mặt nạ / lọc thải không…

- **Mức độ:** Trung bình
- **Trạng thái:** **Partly fixed (30/10/2026)** — người dùng chốt tạm ≤ 0,01 % cho BSC/LAF; phòng sạch H13 ≤ 0,1 % đã làm. Còn lux LAF

## Mô tả

HEPA: code chỉ có mức ≤ 0,01 %; BSC.01/BSC.02 có mức ≤ 0,005 % khi scan qua mặt nạ / lọc thải không tiếp cận. `LAFBSCHandler` ghi cứng lux ≥ 750 (LAF.01: theo NSX).
